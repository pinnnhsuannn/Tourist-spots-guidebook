# 📖 日日旅行手札・景點小幫手 (Travel Journal Guide)

一個輕量、免編譯、支援離線瀏覽與 GitHub Pages 一鍵部署的個人旅遊景點手帳網站。以日系無印雜誌風與旅行日記本為設計概念，收納心動的日本景點與深度攻略。

---

## ✨ 網站特色

- **📖 旅行手帳 3D 翻頁體驗 (Journal Flip Card)**：
  - **正面**：日系和紙膠帶＋拍立得相框照片、景點標題、精華特色與可愛手繪風座標標記。
  - **背面**：深度攻略筆記（詳細介紹、門票費用、營業時間、建議停留時間、交通指南與避坑提醒）。
- **🔍 即時關鍵字搜尋**：即時過濾景點名稱、特色亮點、詳細心得或交通關鍵字。
- **🏷️ 多維度手帳索引標籤**：依地區（北海道、關東、關西、中部等）及主題分類（絕景自然、世界遺產、主題樂園、經典溫泉）快速篩選。
- **🌿 溫潤日系美學**：暖色米白紙質底色、墨灰印刷文字與柔和的大地色調。
- **⚡ 零編譯純原生**：純 HTML5 + CSS3 + Vanilla JavaScript，無需 `npm` 或打包工具。

## 🚀 GitHub Pages 啟用教學

將本專案推上 GitHub 後，只需以下三步即可擁有線上公開網站：

1. 前往 GitHub 倉庫頁面，點擊上方選單的 **Settings**（設定）。
2. 在左側側邊欄點選 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，並點擊 **Save**。
4. 等候 1-2 分鐘，即可獲得你的專屬線上網址（例如：`https://pinnnhsuannn.github.io/Tourist-spots-guidebook/`）！
